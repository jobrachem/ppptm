Smallest seam: replace only HDist’s onion partial with the upstream factory; keep the pseudo route. Existing-location Model.init_dist(samples) then remains structurally unchanged.

For posterior prediction at new locations, use graph.predict(samples, newdata=..., predict=[coef, *G_kwargs]), then call the stored constructor. The current Model.init_dist has no newdata parameter.

Duplicate API equivalence

  • Every module-level definition in ppptm’s approx.py, mispline.py, and onion.py has the same-name upstream equivalent.
  • TransformationSpline is upstream; only the private, uncalled _broadcast_leading lacks a same-name equivalent.
  • inverse_interpax.py is byte-identical across the two checkouts.
  • The only external ppptm caller is the spatial-onion notebook’s OnionSpline.dot_and_deriv; the upstream method remains available.

Native Liesel plotting

result.plot_params(position=None, legend=True, title=None, subset=None, window=None) returns a plotnine.ggplot.

The six notebooks can replace filtered temporary dictionaries with:

result.plot_params(subset=[name for name in position if "amplitude" in name])

Passing the old dictionary directly is also possible as result.plot_params(position=d), but subset removes the extra comprehension result.

Ownership

liesel_ptm: make pseudo spline-only methods broadcast identity results to the distribution batch shape. This is a general distribution defect, reproduced without ppptm.

ppptm: use the onion factory, use a scalar identity dummy coefficient, align public inputs with posterior batch axes, and expose the new-location prediction route.

ppptm: delete duplicates and update notebooks only after those behavior tests pass.
